# Nivedha Portfolio

## Files
- index.html
- style.css
- script.js
- images/profile.jpg (add your photo here)
- resume.pdf (add your resume here)

## Run
Open `index.html` in VS Code and use Live Server.

## Before publishing
1. Replace `yourmail@example.com` with your email.
2. Replace the GitHub placeholder with your GitHub profile.
3. Add your profile photo as `images/profile.jpg`.
4. Add your resume as `resume.pdf`.
5. Replace project `#` links with your real project links.
